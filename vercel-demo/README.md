# Demo Vercel — FERTISEM Envíos PRO

Demo pública y sanitizada del flujo de cálculo del plugin.

## Seguridad

Los importes, rangos y zonas de esta demo son ficticios. No se publican tarifas comerciales reales, asignaciones internas reales, URLs operativas ni datos de clientes.

## Publicar en Vercel

1. En Vercel, elige **Add New → Project**.
2. Importa el repositorio `jhuniorgalvesll/inicio` desde GitHub.
3. En **Root Directory**, selecciona `vercel-demo`.
4. Framework Preset: **Other**.
5. No necesita Build Command ni variables de entorno.
6. Pulsa **Deploy**.

Vercel publicará el archivo `index.html` como una demo estática e interactiva.
